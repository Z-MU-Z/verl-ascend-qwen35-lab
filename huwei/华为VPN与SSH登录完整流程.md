## 6. 路由配置

这是最容易遗漏的一步。VPN 隧道建起来，并不代表目标服务器一定走 VPN。

### 6.1 先加文档要求的路由

在“路由设置”中添加：

- IP 地址：`10.1.3.2`
- 子网掩码：`255.255.255.255`

如果一开始是 `Mode Config` 被选中、导致路由区域是灰色的，需要切换到允许手工填写路由的模式，再点击右侧 `+` 号添加。

> 插图建议 3：路由设置区域中，手工添加路由输入框从灰色变为可编辑的截图。
>
> 插图建议 4：新增地址弹窗中填写 `10.1.3.2 / 255.255.255.255` 的截图。

### 6.2 再加服务器实际访问路由

实际连接中发现，仅添加 `10.1.3.2/32` 不足以访问华为服务器 `172.20.117.36`。需要继续添加服务器地址路由。

推荐两种方式任选其一：

方式 A：逐台添加

- `172.20.117.36` / `255.255.255.255`
- `172.20.117.37` / `255.255.255.255`

方式 B：按网段添加

- `172.20.117.0` / `255.255.255.0`

建议保留 `10.1.3.2/32` 不删除，再额外补上服务器路由。

## 8. 验证服务器是否真的走 VPN

这一步非常重要。之前出现过“VPN 已登录成功，但服务器 IP 仍走本机默认网关”的情况。

连接 VPN 后，在本地终端执行：

```bash
route -n get 172.20.117.36
```

正确结果应类似：

```text
route to: 172.20.117.36
gateway: 192.168.65.249
interface: utun5
```

关键点：

- 如果 `interface` 是 `utunX`，说明流量走了 VPN
- 如果 `interface` 是 `en0`，说明还没走 VPN，需要回去检查路由设置

也可以进一步验证连通性：

```bash
ping -c 3 172.20.117.36
nc -vz -w 5 172.20.117.36 22
```

本次实测结果：

- `ping 172.20.117.36` 成功
- `22/tcp` 连通

## 10. 创建普通用户并配置 SSH 免密

为了避免长期使用 root 登录，建议创建个人用户，并下发本地 SSH 公钥。

### 10.1 本地检查公钥

在本机执行：

```bash
ls -la ~/.ssh
cat ~/.ssh/id_rsa.pub
```

本次实际使用的是本地已有公钥：

- `~/.ssh/id_rsa.pub`

### 10.2 远端创建用户

以 root 登录远端后，执行：

```bash
useradd -m -s /bin/bash zmz
install -d -m 700 -o zmz -g zmz /home/zmz/.ssh
```

然后把本机公钥写入：

```bash
cat > /home/zmz/.ssh/authorized_keys <<'EOF'
<你的本地 SSH 公钥内容>
EOF
chown zmz:zmz /home/zmz/.ssh/authorized_keys
chmod 600 /home/zmz/.ssh/authorized_keys
```

验证用户是否已创建：

```bash
id zmz
ls -ld /home/zmz /home/zmz/.ssh
ls -l /home/zmz/.ssh/authorized_keys
```

### 10.3 验证免密登录

在本地测试：

```bash
ssh -o BatchMode=yes zmz@172.20.117.36 'whoami && hostname && pwd'
```

如果看到类似输出：

```text
zmz
localhost.localdomain
/home/zmz
```

说明免密登录已经生效。

## 11. 配置本地 SSH 别名

为了以后更方便连接，可以在本地 `~/.ssh/config` 中增加别名：

```sshconfig
Host huawei36
  HostName 172.20.117.36
  User zmz
  Port 22
  IdentityFile ~/.ssh/id_rsa
  IdentitiesOnly yes
```

添加完成后，直接执行：

```bash
ssh huawei36
```

即可登录。

本次实际已验证该别名可用。

## 12. 完整推荐操作顺序

建议以后按下面顺序做：

1. 从华为邮件中确认 VPN 账号、VPN 密码、服务器密码
2. 安装 `UniVPN` / `SecoClient`
3. 新建 `L2TP/IPSec` 连接
4. 配置 `121.37.53.218`、`Ins`、`CHAP`、`Huawei@123`
5. 在路由设置里至少加入：
   - `10.1.3.2/32`
   - `172.20.117.36/32`
   - `172.20.117.37/32`
6. 连接 VPN，确认出现“协商成功”与“登录成功”
7. 用 `route -n get 172.20.117.36` 检查是否走 `utun`
8. 用 `ping` 或 `nc` 检查连通性
9. 用 `ssh root@172.20.117.36` 登录
10. 创建普通用户
11. 下发本地公钥
12. 配置 `~/.ssh/config`
13. 以后直接 `ssh huawei36`

## 13. 常见问题

### 13.1 VPN 显示登录成功，但服务器 ping 不通

优先检查路由，而不是先怀疑密码或服务器。

执行：

```bash
route -n get 172.20.117.36
```

如果输出里是 `interface: en0`，说明没有走 VPN。

### 13.2 路由输入框是灰色，不能添加

通常是因为当前处于 `Mode Config` 自动模式。切换到可手工配置路由的模式后，再点 `+` 添加。

### 13.3 首次 SSH 提示主机指纹确认

这是正常现象。确认目标主机无误后输入：

```bash
yes
```

### 13.4 以后不想每次输入 IP

把连接信息写进本地 `~/.ssh/config`，之后用别名登录，例如：

```bash
ssh huawei36
```
