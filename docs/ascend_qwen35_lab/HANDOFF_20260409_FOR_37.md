## Hidden Runtime Dependencies Already Learned

On `.36`, the minimal isolated `2.9` env also needed:

- `PyYAML 6.0.3`
- `numpy 1.26.4`
- **`torchvision 0.24.0`** (before first vLLM Qwen3.5 rollout smoke)

Reason:

- `torch-npu 2.9.0` wheel metadata did not fully describe those runtime imports
- `torch_npu` import failed until both were added
- vLLM’s `Qwen3_5ForConditionalGeneration` path imports VL helper code that pulls in `torchvision`; without it, the HTTP server fails with a vague `VllmConfig` “failed to be inspected” error (see `KNOWN_ISSUES.md` §9). Install with **`pip install torchvision==0.24.0 --no-deps`** so `pip` does not upgrade `torch`.

So on `.37`, do not stop after installing only:

- `torch 2.9.0`
- `torch_npu 2.9.0`

Also expect to need:

- `PyYAML`
- `numpy`
- `torchvision` (pinned, `--no-deps`)
